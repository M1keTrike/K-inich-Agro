# Data Model: Módulo de Entornos Dinámicos

## Entities

### `DynamicResource`
Represents a single variable tracked by the system.
- **Fields**:
  - `id` (string): Unique identifier (e.g., `"oxygen_level"`).
  - `current_value` (float): The current state metric.
  - `max_value` (float): The upper boundary or total capacity.
  - `min_value` (float): The lower boundary (critical for environmental constraints).
  - `unit` (string): Display unit (e.g., `L`, `°C`, `%`).
  - `type` (enum `[consumable, environmental]`): Dictates how the genetic engine evaluates the resource.
  - `priority_weight` (float): Mathematical weight (`0.0 - 1.0`) used in fitness functions to determine criticality.

### `ScenarioTemplate`
A predefined configuration payload for injecting an entire scenario event.
- **Fields**:
  - `template_id` (string): Unique identifier (e.g., `"dust_storm_01"`).
  - `name` (string): Human-readable name.
  - `description` (string): Brief context for the users.
  - `resources` (Array of `DynamicResource`): The new state variables that replace or merge with the current simulation state.

### `GeneticResult`
The output of the N-dimensional algorithm containing the Top-3 scenarios.
- **Fields**:
  - `vital_priority` (ScenarioResult): Outcome heavily weighted towards immediate survival.
  - `long_term_sustainability` (ScenarioResult): Outcome heavily weighted towards preventing resource depletion over time.
  - `equilibrium` (ScenarioResult): Balanced outcome.
  - `sociological_analysis` (string): The justification text generated by the OpenRouter LLM based on the governance knowledge base.
